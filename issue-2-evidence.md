## Scope and contract decisions

Core models/schemas cover Scenario, Environment, Replay Plan, Planner Input/Decision, Run/Result, explicit Scenario registry and external adoption evidence. GOAL-001 and FILE-001..004 are represented without executing games, arbitrary code, Gua native, network or Codex. OPEN-01/04 reuse pinned Gua 1.1.1; OPEN-08 uses bytes SHA-256, no self-hash, full Recording boundaries and external evidence; OPEN-10 requires finite explicit limits; OPEN-12 maps actual Issues and model names. OPEN-03 was already closed by Gua's Observe contract. OPEN-02/05/06 remain their owners' comparison/time/result semantics, not reimplemented here.

The original 126 requirements remain. DASH-001..004 add #26's explicit registry population, stable Scenario/version/hash, actual build/effective Environment identity, faithful saved status/history and read-only roots/refresh/Viewer/distribution boundary. BOUND-005 preserves planning authorization separately from the current implementation and gated-merge request.

## Reproducible commands and independent oracles

```powershell
dotnet restore --locked-mode
./scripts/check-boundaries.ps1
dotnet build --no-restore -c Release
dotnet test --no-build --no-restore -c Release --logger trx --results-directory artifacts/tests
./scripts/contract-smoke.ps1
./scripts/package-smoke.ps1 -Rid win-x64
dotnet run --no-build -c Release --project src/Gua.Playtest.Cli -- validate --allow-root fixtures/contracts fixtures/contracts/plan.json
```

Windows .NET SDK 10.0.401 is the local environment; the CI matrix uses SDK 10.0.301 on win-x64/linux-x64/osx-x64/osx-arm64. Exact executing head, TRX files, smoke evidence JSON and archive/tool evidence are captured as CI artifacts. Local artifact paths are under ignored `artifacts/tests` and `artifacts/contracts-<unique>`; their command records identify head and native removal count. CI success on the final head and real GitHub review are separate merge gates, recorded in the PR rather than inferred from local tests.

The contract suite uses checked-in `fixtures/contracts/expected.json` codes and handwritten assertions, not results generated by the validator. Cases include normal JSON/YAML model equality, duplicate/unknown fields, tags/aliases/cycles/merge keys/multiple documents/nonfinite numbers, types/versions, exact byte hash changes, retained input copies, entry cwd vs containing-file references, parent/sibling/junction or symlink escape, secret-marker diagnostics, registry identity, checkpoint coverage/wait conflicts, cancellation, every Decision branch, prohibited Planner controls, typed enum collections and every ResultStatus. Pinned vendor manifest hashes and embedded text are compared. Windows junction creation and Unix symlink creation must actually succeed; no skip substitutes for the path fault.

Published native-free smoke copies all fixture files into a new stage, changes cwd, removes actual Gua native payloads, runs every committed expected case using the published CLI and confirms `doctor --native` fails. This proves packaged schema parsing without source/native/engine/Planner requirements. The separate #3 archive/Tool smoke validates real package closure and native load; it does not establish gameplay.
