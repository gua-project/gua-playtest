# Run artifact persistence (P-08, issue #9)

`Gua.Playtest.Runner.Artifacts` owns local Run summaries and associations, not Gua Trace/Recording formats or a Viewer. Its sources live in `Runner/Persistence` because the repository ignores directories named `artifacts`. The trusted execution owner serializes calls; callbacks and Planner output have no storage/result authority. A private, trusted output root is required: reparse points are rejected, but this is not an OS sandbox against another process concurrently modifying the directory.

## Integration boundary

1. Create `RunArtifactStore` with an explicit root, `ArtifactLimits` and host-only `PersistenceRedactor`. A random Run identity, separate directory and exclusive owner marker prevent Run reuse. Creation can fail before any file exists; the host must classify that as persistence failure, not infer a Run result.
2. At Preparing entry, before launch/connect, call `BeginPreparation`. It publishes `run.json`: profile/public scope, effective settings with source, used versions, sanitized fixed input copies and SHA-256 of those copies. Source inputs, environment variables, resolved secret values and raw pre-redaction hashes are never copied. Secret references/availability may be explicit safe settings. The existing public Run wire document is assembled by #15; this storage envelope does not replace its schema.
3. At primary confirmation, before cleanup, call `ConfirmPrimary` with #6's immutable `PrimaryResult`, exception evidence and observation/decision references. `primary.json` is create-only. Before/After/PrimaryDecision references cannot contain AfterCleanup; cleanup references are written separately. No result is derived from an observation. A failed primary write still freezes the in-memory primary and marks persistence incomplete.
4. After cleanup, call `Complete` with the same primary in `RunOutcome`, exactly one Trace and one Recording receipt, and only AfterCleanup references. `completion.json` stores associations/postprocessing separately. `result.json` uses the existing `ResultDocument` schema, with unchanged primary status/phase/origin/reason and aggregated postprocessing. It is published last and once. #15 must carry every operation's `PersistenceResult` into postprocessing and use its exit projection. Earlier storage failure cannot be forgotten by a successful final write.
5. `RunArtifactReader.ReadResultAsync` independently uses the existing static contract validator. Missing result is Missing; truncated/wrong-schema/identity-mismatched result is Invalid. Neither a primary Passed snapshot, final observation nor a pending file supplies a missing final result.

The current #6 `RunExecutor` enters cleanup without a primary-snapshot callback. Integration must call `ConfirmPrimary` at that boundary even on cancellation; registering an ordinary Diagnostics callback is insufficient because cancellation can skip that work. #6/#15 own this assembly. #8's `IPreparationTrace.Record(PreparationEvent(Stage, Code))` must connect to the common Gua adapter before launch, not to a new Playtest timeline. Artifact persistence itself does not produce lifecycle Trace events.

## Gua-owned receipts and safety

`ArtifactReceipt` separates `NotExecuted`, `OmittedOnSuccess`, `CaptureFailed`, `SaveFailed` and `Saved`. Only Passed permits success omission. Non-saved states contain no file/byte/hash fields and create no empty artifact. Capture/flush failures add ArtifactFailed to postprocessing; Passed plus incomplete postprocessing exits 11, while non-Passed primary exits are preserved.

A Saved receipt names a nonempty, bounded, local file with a fixed safe basename, byte length and lowercase SHA-256. Trace and Recording cannot alias the same file. Readback rejects traversal, URL paths, summary replacement, linked paths, length/hash mismatch and Run capacity overflow. Bytes are opaque: tests use opaque fixture bytes and do not claim a Gua format reader or actual Gua integration. The concrete Gua writer must redact before its own queues/buffers/hashes and supply genuine capture/flush evidence. A receipt is not proof that an unimplemented upstream writer satisfies this requirement.

The host supplies all resolved secret values and sensitive field names. String deletion is idempotent; sensitive fields/settings become null, preserving the distinction from a supplied empty value. Property names are sanitized and collisions rejected. The bounded sanitized tree is built before UTF-8 storage buffers or hashes. Exception type/stack are sanitized for disk; the original #6 `RunOutcome` remains untouched. Exception messages/inner exceptions and raw Planner text are not collected. #11's `PlannerDecisionReference` maps only identifiers and its structured enum code into `DecisionReference`; pinned Planner schema has no free rationale field. Host metadata/expected criteria are never returned to Planner.

Explicit `ArtifactLimits` bound per-file bytes (256..16 MiB), total associated Run bytes (up to 256 MiB), node/reference count (up to 100000), string chars and depth (32). These hard ceilings are not product defaults. The trusted configuration owner supplies stricter effective Environment limits. Same-directory temporary files use CreateNew, flush-to-disk and create-only rename; normal failures remove pending files. A process interruption can leave pending bytes and absence of final result; no complete-save claim follows. Local filesystem flush is synchronous and is not a hard real-time deadline guarantee. #6 cleanup/adapter isolation must bound provider work; no install or publication is introduced.

## Acceptance evidence and remaining integration

`ArtifactTests` independently parses saved JSON, verifies fixed-copy hash, checks secret absence across every file, validates final result against the existing schema, injects wrong hash/disk target collision/cancellation/byte limit/truncated result, checks observation boundary and primary replacement rejection, and checks all non-saved artifact states and exit 11. This is local contract evidence for AT-FILE-007, AT-FILE-006, AT-RUN-005/006 and part of AT-TRACE-006/007/009 and AT-PLANNER-009.

Still OPEN: Gua-owned common Trace registration from Preparing, real capture/flush/Recording association, recent/streaming × onFailure/always combinations, intermediate Change/gap rendering, actual Viewer readback, real host/Planner/CLI assembly and bounded provider cancellation. These require #7/#8/#11/#15/#16 and Gua T-04 (#126). Published Gua.Testing remains 1.1.1; unpublished guarded APIs are not used. Keep issue #9 open until those independent real acceptance tests pass. No Fake or local schema success closes that integration requirement.
